# growth-directions-in-twisted-crystal-planes
Tool to analyze twisted spherulite growth and determine the change in crystal planes

The goal of this project is to analyze large batches of data and determine the direction of crystal growth in twisted crystals for a given region. GI-WAXS Data collected from Brookhaven National Lab was entered into Datasqueeze to extract 1D diffraction data for a selected q-space.
